# Technology Stack

Java/Spring Boot, Spring Data JPA, Hibernate, PostgreSQL, Spring Cloud Config, Eureka, reactive Gateway and Spring Cloud LoadBalancer. Use versions and build tooling from actual module files. JUnit Jupiter, Mockito, Spring Boot test support and PostgreSQL Testcontainers are preferred where compatible. Planned Kafka, Keycloak, Docker/Kubernetes, Terraform and FastAPI/LangGraph are not required for current CRUD. No Flyway; local Hibernate ddl-auto update. Production schema changes require a separately approved strategy.
