# Create or modify service boundaries

Confirm ownership, dependencies and ports from repository. Do not create a new service without user approval. Use separate database ownership, config and discovery as applicable. Verify standalone API first, then gateway and multi-instance routing. Add service and integration tests; test routing when changed.

Follow AGENTS.md and applicable rules. Report verification and blockers.
