# Write isolated Java unit tests

Use JUnit Jupiter and Mockito extension when needed. Arrange Act Assert; verify meaningful behavior and side effects. For Project creation test slug normalization, duplicates, invalid slug and persistence; for update/archive test missing IDs and state transitions. Avoid testing getters or implementation details. No network or database.

Follow AGENTS.md and applicable rules. Report verification and blockers.
