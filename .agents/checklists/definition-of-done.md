# Definition of done
- [ ] Requirements met and scope preserved.
- [ ] Unit tests added or updated for changed behavior.
- [ ] Integration tests added or updated for affected boundaries; any non-applicability explained.
- [ ] Success and relevant failure cases covered.
- [ ] Targeted tests and affected module verification executed; actual outcomes recorded.
- [ ] No skipped tests concealed; blockers explicitly reported.
- [ ] Validation, authorization, transactions and database constraints reviewed.
- [ ] No secrets, destructive changes or unapproved dependencies.
- [ ] API documentation and verified project context updated where needed.
- [ ] Final report includes assumptions, limitations and remaining risks.

If required checks cannot run, mark verification incomplete, not done.
