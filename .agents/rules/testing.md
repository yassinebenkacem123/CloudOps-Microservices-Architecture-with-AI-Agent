# Testing

Every behavior change must include unit and applicable integration coverage. Unit: JUnit Jupiter/Mockito, no Spring context unless needed. MVC slice: @WebMvcTest with version-compatible mock bean annotation; assert status, JSON and validation. Repository: @DataJpaTest with real PostgreSQL where database semantics matter. Integration: @SpringBootTest with PostgreSQL Testcontainers, real service/repository and HTTP or MockMvc; isolate config/discovery from external servers in test profile. Use dynamic datasource properties or compatible @ServiceConnection. Never use production credentials or databases. Cover happy path, edge cases, errors and regressions. Tests must be deterministic, independent and clean up data. Mock external APIs at HTTP boundary when relevant. Run Maven wrapper if present (Windows mvnw.cmd, Unix ./mvnw), otherwise mvn; use test and verify. Ensure integration test naming and Failsafe configuration actually execute tests; inspect reports. If Docker is unavailable report blocked integration tests, do not silently substitute H2 or claim success. No arbitrary coverage target; meaningful assertions required.
